为什么做 PagViewer

看一眼 PAG，
原本没那么顺手

PAG 是腾讯开源的动效格式，微信红包、王者荣耀、直播礼物里都在用。但每次想确认导出的 .pag 是否正常，过去的办法都很折腾：

QuickLook + PagViewer 选择文件 → 按空格 → 预览动画

QuickLook 的「选中文件、按空格即刻预览」是我离不开的效率习惯。可惜它一直没有 PAG 支持。

于是我做了 PagViewer —— 把「空格即看」带到 PAG 文件上，随手检阅动画是否达标，不必开软件、不必上传。

前提：装好 QuickLook（Windows 版 QL-Win），再装这个插件。

功能

空格一按，即刻预览

不用先打开专门的播放器。在资源管理器中选中 PAG 文件，按下空格，PagViewer 就会接入 QuickLook 预览流程，自动循环播放动画。

播放细节，随时掌控

播放、暂停，或拖动时间轴定位到想看的瞬间。通过音量按钮、滑块和滚轮调整声音；停止操作后，控制栏会自动隐藏，让画面回到主角。

透明背景，清晰可见

在棋盘格、白色、黑色与自定义背景之间切换，检查透明区域和边缘。按住 Ctrl 滚动缩放，长按拖动画布，让局部细节也能看得清楚。

文件信息，一眼读懂

悬停信息按钮即可查看尺寸、时长、帧率和图层数等信息。结合 FPS 显示与进度条的性能反馈，在检查动画效果时，也能留意文件的渲染状态。

查看完整能力

需要的画面，保存下来

定位到需要的画面，将当前帧保存为 PNG，直接留在 PAG 文件旁边。也可以复制原文件到剪贴板，继续整理、传递或处理素材。

先装本体，再装插件

PagViewer 为 Windows QuickLook 增加 PAG 支持。请先安装、启动 QuickLook，再打开插件安装包。

  1. 安装 QuickLook 4.x，并保持运行。
  2. 从 PagViewer Releases 下载 .qlplugin。
  3. 选中安装包，按空格，点击安装。
  4. 重启 QuickLook，选中 .pag 文件后按空格。

安装与开始使用

先装 QuickLook 本体，
再装 PagViewer 插件。

PagViewer 是插件，需要 QuickLook 本体提供空格预览窗口。第一次使用，请先安装并运行 QuickLook。

QuickLook 本体 → PagViewer 插件
  1. 1

    安装 QuickLook 本体

    下载 Windows 版 QuickLook，安装并启动，确认它正在系统托盘运行。

    下载 QuickLook 本体 ↗
  2. 2

    下载 PagViewer 插件

    从 PagViewer Releases 获取 .qlplugin 文件；源码 ZIP 不是插件安装包。

    下载最新版 .qlplugin ↓
  3. 3

    选中安装包，按空格安装

    保持 QuickLook 运行，在资源管理器中选中 .qlplugin，按空格，在弹出的窗口中点击安装。

    Space → 安装
  4. 4

    重启 QuickLook，开始预览

    安装完成后重启 QuickLook。选中任意 .pag 文件，再按空格即可预览动画。

开始之前，你可能想知道

需要先安装 QuickLook 吗？

需要。PagViewer 是 QuickLook 4.x 的插件，需要配合 QuickLook 使用。

支持 macOS 吗？

此插件面向 Windows 10/11，不是 macOS 的 Quick Look 扩展。

导出的 PNG 保存在哪里？

当前帧导出的 PNG 会保存在 PAG 文件旁边。
