为什么做 PagViewer

预览 PAG 动画，原本没那么方便

PAG 是腾讯开源的跨平台动画格式，广泛应用于游戏、短视频、直播等场景。但预览 PAG 文件需要专门的播放器，无法在资源管理器中快速确认。

缺少便捷预览工具 预览 PAG 动画需要打开专门的播放器，无法在资源管理器中快速确认
开发调试不便 设计师和开发者需要频繁确认导出的 PAG 动画是否正确，但缺少便捷的本地预览工具
实时渲染 使用 libpag WebAssembly 引擎进行实时渲染。
为检查而生 播放、暂停、进度条、音量控制和背景检查集中在一处。
需要时导出 将当前画面保存为 PNG，文件仍留在原目录。

PagViewer for QuickLook ⊞从源码构建

Windows 10/11 · QuickLook 4.x · WebView2 Runtime · GPL-3.0

安装只需三步

  1. 1
    下载插件

    从 GitHub Releases 获取 .qlplugin 文件。

  2. 2
    空格安装

    在资源管理器中选中该文件按空格，在 QuickLook 预览窗里点击「安装」。

  3. 3
    重启即用

    重启 QuickLook，回到任意 .pag 文件按空格即可预览动画。

从源码二次开发

PagViewer 是开源的 .NET 插件，欢迎基于它改播放逻辑、扩展导出格式或移植到其他平台。

前置要求

  • Windows 10 / 11
  • QuickLook 4.x
  • WebView2 Runtime（通常已预装）
  • .NET SDK

克隆并构建

git clone .../QuickLook.Plugin.PagViewer.git
cd QuickLook.Plugin.PagViewer
dotnet build -c Release

打包为 .qlplugin

powershell -ExecutionPolicy Bypass `
  -File Scripts/build.ps1

产物为 .qlplugin，装回 QuickLook 即可验证。

项目结构

Plugin.cs                  # IViewer 入口
PagViewerPanel.xaml(.cs)   # WebView2 播放面板
Resources/Web/             # libpag WebAssembly / 播放器 UI
Samples/                   # 测试用 PAG 示例文件
Scripts/                   # 打包脚本
*.csproj / *.sln
