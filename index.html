为什么做 PagViewer

看一眼 PAG，原本没那么顺手

PAG 是腾讯开源的动效格式，微信红包、王者荣耀、直播礼物里都在用。但每次想确认导出的 .pag 是否正常，过去的办法都很折腾：

装 AE 插件得先开 After Effects，装好 PAGExporter 才能导出预览

QuickLook 的「选中文件、按空格即刻预览」是我离不开的效率习惯。可惜它一直没有 PAG 支持。

于是我做了 PagViewer —— 把「空格即看」带到 PAG 文件上，随手检阅动画是否达标，不必开软件、不必上传。

前提：装好 QuickLook（Windows 版 QL-Win），再装这个插件。

看 PagViewer 如何工作

在资源管理器里选中任意 .pag 文件，按空格即可唤起带播放、检查与导出的预览窗。

就在文件旁边选中 .pag 文件，再按空格预览。
为检查而生播放、缩放、拖拽和背景检查集中在一处。
需要时导出将当前画面保存为 PNG，文件仍留在原目录。

PagViewer for QuickLook⊞从源码构建

Windows 10/11 · QuickLook 4.x · WebView2 Runtime · GPL-3.0

安装只需三步

  1. 1
    下载插件

    从 GitHub Releases 获取 .qlplugin 文件。

  2. 2
    空格安装

    在资源管理器中选中该文件按 空格，在 QuickLook 预览窗里点击「安装」。

  3. 3
    重启即用

    重启 QuickLook，回到任意 .pag 文件按 空格 即可预览动画。

从源码二次开发

PagViewer 是开源的 .NET 插件，欢迎基于它改播放逻辑、扩展导出格式或移植到其他平台。

前置要求

  • Windows 10 / 11
  • QuickLook 4.x
  • WebView2 Runtime（通常已预装）
  • .NET SDK

克隆并构建

git clone .../QuickLook.Plugin.PagViewer.git
cd QuickLook.Plugin.PagViewer
dotnet build -c Release

打包为 .qlplugin

powershell -ExecutionPolicy Bypass `
  -File Scripts/build.ps1

产物为 .qlplugin，装回 QuickLook 即可验证。

项目结构

Plugin.cs                  # IViewer 入口
PagViewerPanel.xaml(.cs)   # WebView2 播放面板
Native/                    # P/Invoke 桩代码
Resources/Web/             # libpag SDK / wasm / 播放器 UI
Samples/                   # 测试用 PAG 示例文件
Scripts/                   # 打包脚本（build.ps1）
*.csproj / *.sln
